# API / Reference (Example)

## HTTP `/api/skills/{id}`

- `resource_path`: Relative path inside the package, such as `FORMS.md` or `scripts/payloads.txt`.
- `depth=summary`: Return only the summary and directory, suitable for the first lookup.

## Multi-Agent Runtime

- Use the Eino ADK **`skill`** tool to progressively load skill packages; optionally enable `multi_agent.eino_skills.filesystem_tools` to access package files.
